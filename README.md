# SemenBanan 🍌

Python-бот для Telegram с генерацией реплик через твой OpenClaw Gateway.

Рабочая папка на этом компьютере: `C:\Programming\2026\SemenBanan`.

## Где смотреть код

| Файл | Назначение |
|---|---|
| `bot.py` | Приём сообщений Telegram, запросы к OpenClaw и отправка ответов |
| `audio_job.py` | Запуск отдельного процесса генерации, ожидание и остановка |
| `audio_worker.py` | Одно задание: загрузить модели, создать OGG и завершиться |
| `piano.py` | NanoMaestro и озвучивание пианино через FluidSynth |
| `arrangement.py` | Барабаны, Piper и сведение трёх дорожек |
| `memory.py` | Цепочки ответов, характер и очередь в SQLite |

## Уже настроено на этом компьютере

Токен проверен, группа `-1004478700126` сохранена в локальном `.env`, privacy отключён. Агент `semyon` создан, конфигурация OpenClaw прошла проверку, тестовый запрос через Gateway вернул «Банан.». Исходный конфиг Gateway сохранён рядом с ним в резервную копию `openclaw.json.before-semyon-1792692393`.

Бот первоначально запущен в фоне. Чтобы остановить этот экземпляр:

```powershell
powershell -ExecutionPolicy Bypass -File .\stop.ps1
```

Для следующего запуска используй `start.ps1` по инструкции ниже. Это запуск вручную, не автозагрузка Windows. Архив ZIP не содержит токенов, привязки к группе и личной переписки: `.env` и `memory.sqlite3` остаются только локально.

Фоновый запуск из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Background
```

Журналы фонового запуска — в `.runtime/stdout.log` и `.runtime/stderr.log`.
`stop.ps1` останавливает всё дерево процессов проекта, включая текущую генерацию.

## Поведение

- Только ответы на новые сообщения в разрешённой группе. Никаких таймеров, приветствий и самостоятельных публикаций.
- «Семён», «Семен», «Сеня», точное @имя бота или ответ на сообщение Семёна — ответ при свободном интервале. При ответе на его сообщение текст исходной реплики передаётся модели для контекста.
- Если следующее сообщение отвечает на предыдущее в цепочке с Семёном, он распознаёт продолжение и отвечает даже без имени. Цепочка может проходить через сообщения других участников. Обращения в течение десятисекундного интервала ставятся в очередь.
- Явная просьба изменить характер или манеру речи («Семён, будь добрее», «поменяй характер», «без мата») запоминается для всей группы. Последующие просьбы имеют приоритет над прежними; границы безопасности персонажа остаются в силе.
- «банан», «бананы», «шучу бананы», слова с основой «банан», banana/bananas или 🍌 — вероятность ответа 25%.
- По просьбе «Семён, сыграй на пианино», «сыграй что-нибудь» или «сочини мелодию» бот сочиняет через тот же OpenClaw Gateway мелодию и четыре аккорда, играет пьесу через FluidSynth с банком GeneralUser GS и отвечает голосовым сообщением. Явную просьбу сыграть распознаёт и без имени. Музыкальная просьба всегда попадает в обработку, но соблюдает общий интервал 10 секунд и при необходимости ждёт очереди.
- «Семён, сыграй через NanoMaestro» или «сыграй через локальную модель» включает NanoMaestro Light. Начальный такт и темп придумывает OpenClaw по просьбе участника, ещё три такта продолжает локальная модель на CPU. Озвучивание тем же пианино. Веса модели занимают около 14 МБ; она загружается только в отдельном процессе текущей записи.
- Музыкальный ответ по умолчанию содержит три отдельные дорожки: пианино, барабаны и короткую русскую речь Семёна поверх музыки. OpenClaw придумывает барабанный рисунок и текст, а Piper Denis синтезирует речь локально на CPU. Во время фраз инструменты приглушаются. «Сыграй только пианино» отключает обе дополнительные дорожки; «без речи» и «без барабанов» отключают соответствующую партию.
- Между ответами в одной группе минимум 10 секунд. Отдельной паузы в 15 минут нет. Прямые обращения, просьбы о характере и продолжения цепочки ждут своей очереди, даже после перезапуска бота. Банановые сообщения по-прежнему пропускаются во время интервала. Отложенное обращение старше 10 минут удаляется, чтобы бот не отвечал на давно завершившийся разговор.
- Игнорируются чужие группы, личка, другие боты, правки сообщений и сообщения старше двух минут.
- Перезапуск не вызывает ответы на накопившуюся переписку. Интервалы сохраняются в `state.json`, а цепочки и просьбы о характере — в локальном `memory.sqlite3`.
- Для ответа по цепочке модель получает сохранённую ветку до 60 000 символов; при большей длине ранние сообщения остаются в базе, но не помещаются в один запрос. Для нового сообщения вне цепочки передаются последние 12 реплик темы. OpenClaw и поставщик модели могут сохранять переданные запросы по своим настройкам.
- Цепочку, начатую до установки этой версии, Telegram не позволяет восстановить целиком. Ответь на сообщение Семёна или назови его по имени один раз, чтобы начать сохраняемую ветку.
- Персонаж и манера речи — в `persona.txt`: мат, сатира, чёрный юмор, дружеские подколы. Фактический стиль зависит также от модели и её правил.

## Быстрый запуск на Windows

Требуется Python 3.10+ и работающий OpenClaw. Для музыки нужен FFmpeg с кодеком `libopus`: если системного FFmpeg нет, зависимость `imageio-ffmpeg` из `requirements.txt` предоставляет его. Открой PowerShell в этой папке.

При первом запуске `start.ps1` установит Python-зависимости и музыкальные компоненты: переносимый FluidSynth, банк звуков GeneralUser GS, NanoMaestro Light и русский голос Piper Denis (около 63 МБ). Они хранятся в `assets/`, исключены из Git и ZIP. На Linux/macOS FluidSynth устанавливается отдельно.

1. В @BotFather создай бота через `/newbot`. Для уже созданного бота этот шаг пропусти.
2. В @BotFather: `/setprivacy` → выбери бота → `Disable`. После изменения удали бота из группы и добавь заново. Достаточно обычного участника с правом писать.
3. Локальный `.env` уже содержит присланный Telegram-токен. При переносе проекта скопируй `.env.example` в `.env` и заполни секреты вручную. Не публикуй `.env`.
4. Найди ID группы:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 --discover-chats
```

После появления приглашения напиши `/id` в группе. В консоли появится `ALLOWED_CHAT_IDS=-100...`. Этот режим ничего не отправляет в Telegram. Останови его Ctrl+C и внеси число целиком, вместе с минусом, в `.env`. Можно перечислить несколько групп через запятую.

5. Проверь подключение и запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1 --check
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Проверка делает запрос к модели и показывает ответ только в консоли. Для проверки в чате напиши `Семён, ты тут?`. При работе бота окно должно оставаться открытым. Остановка — Ctrl+C. Одновременно запускай только один экземпляр, включая режим поиска групп.

## OpenClaw Gateway

На этом компьютере Gateway найден в WSL-дистрибутиве `OpenClawGateway`, порт `18789`. В настройках включается `gateway.http.endpoints.chatCompletions.enabled=true`; запросы идут на `/v1/chat/completions`, с `Authorization: Bearer <токен Gateway>` и `model: openclaw/semyon`.

Бот использует уже настроенного в OpenClaw поставщика модели. Отдельный API-ключ OpenAI в Python не требуется. Telegram-токен и токен Gateway — разные секреты.

Для переноса на другой Gateway добавь настройки в существующий конфиг, сохранив остальные поля. Пример для OpenClaw с `agents.entries`:

```json
{
  "gateway": {
    "http": {"endpoints": {"chatCompletions": {"enabled": true}}}
  },
  "agents": {
    "ownership": "explicit",
    "defaults": {"systemAgent": {"agentId": "main"}},
    "entries": {
      "main": {},
      "semyon": {
        "name": "Семён",
        "workspace": "/home/openclaw/.openclaw/workspace-semyon",
        "tools": {"deny": ["*"]},
        "heartbeat": {"every": "0m"}
      }
    }
  },
  "talk": {"agentId": "main"}
}
```

Это фрагмент для слияния, не замена всего файла. Сохрани существующие настройки `main`, модели и авторизации; путь workspace подстрой под машину. Для старой версии с `agents.list` используй её формат записей агентов вместо `entries`.

Для Семёна отключены инструменты и heartbeat. Не подключай этот же Telegram-токен к каналу OpenClaw: сообщения принимает только Python. Заголовок `tool_choice=none` сам по себе не заменяет запрет внутренних инструментов агента.

Проверка и перезапуск внутри окружения OpenClaw:

```text
openclaw config validate
openclaw gateway restart
```

Если Gateway работает в WSL на этом компьютере:

```powershell
wsl -d OpenClawGateway -u openclaw -- sh -lc 'openclaw config validate && openclaw gateway restart'
```

В `.env` укажи `OPENCLAW_BASE_URL=http://127.0.0.1:18789`, `OPENCLAW_AGENT_ID=semyon` и секрет из `gateway.auth.token` как `OPENCLAW_GATEWAY_TOKEN`. Gateway оставляй на локальном интерфейсе или в частной сети.

## Настройки

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `ALLOWED_CHAT_IDS` | Разрешённые группы; пустое значение запрещает запуск |
| `OPENCLAW_BASE_URL` | Адрес Gateway, допускается суффикс `/v1` |
| `OPENCLAW_GATEWAY_TOKEN` | Токен Gateway, либо пароль для режима password |
| `OPENCLAW_AGENT_ID` | Отдельный агент, по умолчанию `semyon` |
| `COOLDOWN_SECONDS` | Общий интервал, по умолчанию `10` |
| `BANANA_PROBABILITY` | Вероятность реакции на бананы, по умолчанию `0.25` |
| `REQUEST_TIMEOUT` | Ожидание модели, по умолчанию `90` секунд |
| `AUDIO_TIMEOUT_SECONDS` | Максимальное время локальной генерации, по умолчанию `90` секунд |

После изменения настроек или персонажа перезапусти Python-бота. В случае сетевой ошибки он пишет причину в консоль. Прямые обращения и музыкальные просьбы остаются в очереди для повторной попытки до 10 минут; банановые ответы не повторяются. Неудачная попытка также включает интервал 10 секунд.

Для музыки модель возвращает только ноты в ограниченном формате. Бот проверяет диапазон нот, длительность и число аккордов, затем локально создаёт стерео OGG/Opus. Голосовое прикрепляется ответом к просьбе, а в памяти цепочки отмечается, что Семён сыграл мелодию. Если Gateway дважды вернул неверные ноты или синтезатор недоступен, просьба остаётся в очереди на повторную попытку до 10 минут. Генерация NanoMaestro ограничена четырьмя тактами и 20 секундами работы.

## Загрузка и освобождение памяти

Бот принимает сообщения без загрузки NanoMaestro и Piper. Для каждого музыкального ответа `audio_job.py` запускает отдельный `audio_worker.py`. Тот загружает только необходимые модели, играет инструменты, сводит звук, кодирует OGG/Opus и завершается. Бот получает готовые байты после завершения процесса; память моделей и звуковые буферы освобождаются до отправки в Telegram.

Задания передаются через стандартный ввод, аудио создаётся во временной папке и удаляется после чтения. Токены Telegram и OpenClaw не передаются в окружение генератора. При превышении `AUDIO_TIMEOUT_SECONDS` или отмене задания останавливается всё дерево генератора. Неудачное обращение остаётся в обычной очереди повторов.

Повторные музыкальные запросы каждый раз требуют загрузки моделей. В отдельном замере на этом ноутбуке короткая запись с полной загрузкой заняла около 10,5 секунды, из них около 5 секунд — загрузка моделей. Ожидание OpenClaw и отправка Telegram считаются отдельно. Утилиты сравнения предназначены для локальных экспериментов и могут держать модели до завершения своего процесса.

## Музыкальные компоненты и сравнение

Пианино использует GeneralUser GS 2.0.3 (около 31 МБ), стерео 48 кГц, небольшую вариацию силы и времени нажатий, педаль с отпусканием на границах тактов и умеренную реверберацию. Перед кодированием голосового громкость выравнивается через FFmpeg. Голосовое кодируется в стерео Opus 96 кбит/с.

Для ручной установки или обновления существующего окружения:

```powershell
python -m pip install -r requirements-music.txt
python setup_music.py
```

Установщик использует закреплённую ревизию модели и контрольные суммы загрузок. Веса ONNX и соответствующий словарь скачиваются согласованной парой. Автоматических загрузок при сообщениях в чате нет. Авторство и лицензии — в `THIRD_PARTY.md`; NanoMaestro использует CC-BY-NC-4.0.

Чтобы сравнить композиторов без публикаций в Telegram:

```powershell
python compare_music.py --output comparison --bars 16 --tempo 110
```

Команда создаёт две записи по 16 тактов с одним тембром пианино: `openclaw-piano.ogg` и `nanomaestro-piano.ogg`, около 37 секунд при темпе 110. OpenClaw сочиняет четыре связанных фрагмента с развитием и завершением; NanoMaestro продолжает их первый такт до общей длины. В `comparison.json` сохраняются исходные ноты, ноты продолжения и время работы локальной модели. Можно выбрать 4, 8, 12 или 16 тактов. Длина обычного ответа бота в чате остаётся 4 такта.

Для сравнения с двумя дополнительными дорожками на тех же нотах:

```powershell
python compare_arrangement.py --source comparison/comparison.json --output comparison/full
```

Команда создаёт два общих микса, отдельно два пианино, барабаны и речь. У обоих композиторов одинаковые барабаны и речевая партия. Реплики произносятся обычным голосом, не поются. Барабаны используют General MIDI канал 10 и уже установленный банк звуков; отдельная тяжёлая модель для их звучания не нужна. Для короткого ответа генерируется одна фраза, для длинного примера — две-три. Длина фразы ограничена 80 символами, рисунок барабанов — 32 ударами на такт.

## Если не отвечает

- На бананы иногда молчит — это заданная вероятность; проверяй обращением по имени, спустя 10 секунд.
- Не видит имя и бананы — отключи privacy в BotFather и заново добавь в группу.
- Не видит группу — проверь `ALLOWED_CHAT_IDS`, минус и актуальный ID после превращения группы в супергруппу.
- `401` — неверный токен Telegram/Gateway или отсутствует авторизация модели; смотри, какой сервис указан в сообщении.
- `404` Gateway — выключен chatCompletions, неверен адрес или не существует агент semyon.
- `409` Telegram — другой экземпляр бота либо ранее настроенный webhook. Останови прежнюю интеграцию. Если у бота есть webhook, удали его средствами прежнего сервиса перед запуском polling.
- Gateway работает, но модель не отвечает — проверь авторизацию выбранной модели в OpenClaw. Наличие запущенного приложения Codex само по себе не подтверждает доступ модели из OpenClaw.
- При медленной модели сообщения обрабатываются последовательно; старые сообщения пропускаются.

```bash
python3 -m venv .venv
. .venv/bin/activate

python setup_music.py
# Установи FluidSynth средствами своей ОС
# Создай .env из .env.example и заполни значения

```

Компьютер и Gateway должны оставаться включёнными. Для постоянной работы используй свою службу запуска; внутри бота нет фоновых рассылок.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Тесты проверяют вызовы, вероятность, очередь ответов и её восстановление после перезапуска, изоляцию тем, молчание вне разрешённой группы, формат запроса Gateway, синтез и кодирование голосового. Проверки генератора также подтверждают завершение процесса после записи и остановку дочерних процессов при отмене и превышении времени. Они не публикуют сообщения.

Документация: [OpenClaw HTTP API](https://docs.openclaw.ai/gateway/openai-http-api), [ограничения инструментов агента](https://docs.openclaw.ai/tools/multi-agent-sandbox-tools), [Telegram voice](https://core.telegram.org/bots/api#sendvoice), [Telegram privacy](https://core.telegram.org/bots/features#privacy-mode), [Telegram polling](https://core.telegram.org/bots/api#getupdates).
