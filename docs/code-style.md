# Стиль Python-кода

Проект использует Python 3.13. Проверки оформления и типов настроены в `pyproject.toml`.

- Функции и методы имеют явный возвращаемый тип; параметры исходного кода и инструментов также аннотированы.
- Доменные структуры описываются TypedDict, dataclass и смысловыми псевдонимами типов. Any остаётся на динамических границах внешних API.
- Docstring пишутся по-русски: короткое назначение, пустая строка, `:param имя:` для каждого аргумента кроме self/cls и `:return:`. Для функций без результата указывается, что значение не возвращается.
- Имена отражают назначение и единицы измерения там, где это важно. Сокращения библиотек NumPy/ONNX допустимы как общепринятые обозначения.
- Проверки входа, подготовка данных, внешние вызовы и обработка результата отделяются пустыми строками. Связанные присваивания остаются вместе.
- Рабочие ошибки и поясняющие комментарии пишутся по-русски. Названия API, переменных окружения, полей JSON и тензоров сохраняют внешний формат.
- Все инструкции модели редактируются в `src/semen_banan/resources/prompts.toml`; в Python остаются загрузка, валидация и подстановка параметров.
- Тяжёлые зависимости, нужные только для аннотаций, подключаются через TYPE_CHECKING.

```powershell
.\.venv\Scripts\python.exe -m ruff check src tests tools
.\.venv\Scripts\python.exe -m ruff format --check src tests tools
.\.venv\Scripts\python.exe -m mypy
```

Ruff проверяет возвращаемые типы, документацию классов и функций. Mypy требует аннотации всех функций приложения и инструментов. Контракты поведения проверяются существующими тестами.
